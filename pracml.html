Deprecated / Obsolete (avoid)

These tags are obsolete in modern HTML — don't use in new projects:

  • <font>, <center>, <big>, <strike>, <tt> — use CSS instead.
  • Old presentational attributes like bgcolor, align, etc. — use CSS.
